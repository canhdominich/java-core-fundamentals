# java-core-fundamentals

Mã nguồn thực hành của khóa học "Java: Nền tảng lập trình, OOP, Collections và JDBC".

Mỗi bài có thể chạy nằm trong thư mục `NN-ten-chuong/NN-ten-bai/`, có README riêng ghi môi trường, cách chạy và danh sách chương trình.

Yêu cầu chung: JDK 17 trở lên. Các bài JDBC cần thêm Docker và MySQL Connector/J (xem README của từng bài).
