# Bài 03 - Interface và lớp trừu tượng: chọn công cụ đúng và kết hợp cả hai

Mã nguồn đi kèm bài học **So sánh interface và abstract class** (chương 7: Interface và lớp trừu tượng) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `Audited.java`
- `BaseDemo.java`
- `Combo.java`
- `Practice.java`
- `Trace.java`
- `fails/`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
