# Bài 01 - Phương thức: khai báo, kiểu trả về, return, ngăn xếp lời gọi và lỗi biên dịch

Mã nguồn đi kèm bài học **Phương thức** (chương 3: Phương thức) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `Bill.java`
- `Breakages.java`
- `CallStack.java`
- `Deep.java`
- `Dup.java`
- `Practice.java`
- `Selfcheck.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
