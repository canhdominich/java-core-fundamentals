# Bài 03 - Nạp chồng phương thức: chọn phương thức lúc biên dịch

Mã nguồn đi kèm bài học **Nạp chồng phương thức (Overloading)** (chương 3: Phương thức) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

- `Deep.java`
- `Phases.java`
- `Pricing.java`
- `Printer.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
