# Bài 02 - Chặn kiểu, ký tự đại diện, PECS và xoá kiểu

Mã nguồn đi kèm bài học **Bounded types và wildcards** (chương 11: Generics) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `BoundsDemo.java`
- `Check.java`
- `PriceBoard.java`
- `PriceSum.java`
- `PriceTools.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
