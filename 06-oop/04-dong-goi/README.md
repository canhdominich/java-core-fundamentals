# Bài 04 - Đóng gói: trường private, getter an toàn, bốn mức truy cập

Mã nguồn đi kèm bài học **Đóng gói (Encapsulation)** (chương 6: Lập trình hướng đối tượng (OOP)) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `CardGuard.java`
- `CardLimit.java`
- `CardShop.java`
- `Leak.java`
- `Naked.java`
- `SetterTrap.java`
- `Trace.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
