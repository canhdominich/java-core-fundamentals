# Bài 03 - Hello World: biên dịch, chạy và đọc lỗi đầu tiên

Mã nguồn đi kèm bài học **Cài đặt Java và chương trình Hello World** (chương 1: Nhập môn Java) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `Boom.java`
- `Door.java`
- `Hello.java`
- `Welcome.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
