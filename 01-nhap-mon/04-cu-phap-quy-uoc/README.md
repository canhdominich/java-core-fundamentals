# Bài 04 - Cú pháp cơ bản và quy ước: tên hợp lệ, quy ước đặt tên, comment và dấu chấm phẩy

Mã nguồn đi kèm bài học **Cú pháp cơ bản và quy ước** (chương 1: Nhập môn Java) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `GateDesk.java`
- `NameCheck.java`
- `PriceDesk.java`
- `TicketBug.java`
- `TicketGate.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
