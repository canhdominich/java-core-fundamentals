# Bài 01 - Mảng một chiều: khai báo, giá trị mặc định, duyệt, sao chép và lỗi thường gặp

Mã nguồn đi kèm bài học **Mảng một chiều** (chương 4: Mảng) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `AliasDemo.java`
- `Breakages.java`
- `ClassScores.java`
- `ScoreBoard.java`
- `Selfcheck.java`
- `Shallow.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
