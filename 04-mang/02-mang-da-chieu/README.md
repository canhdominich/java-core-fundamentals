# Bài 02 - Mảng đa chiều: ma trận, mảng răng cưa, sao chép nông và thứ tự duyệt

Mã nguồn đi kèm bài học **Mảng đa chiều** (chương 4: Mảng) của khóa Java: Nền tảng lập trình, OOP, Collections và JDBC.

## Yêu cầu môi trường

| Thành phần | Phiên bản | Ghi chú |
|---|---|---|
| JDK | 17 trở lên | `java -version` |

## Cách chạy

Mỗi file trong `lesson/` là một chương trình đơn lẻ, chạy thẳng từ mã nguồn, không cần Maven hay biên dịch riêng.

```bash
cd lesson
java TênFile.java
```

## Các file trong lesson/

- `Breakages.java`
- `ClassGrades.java`
- `Extras.java`
- `GradeBook.java`
- `Selfcheck.java`

Mỗi chương trình được giải thích từng dòng trong bài học tương ứng trên nền tảng.
